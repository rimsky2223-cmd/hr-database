| 2   | 名詞解釋 | [[勞工]]=>從事工作獲取工資                                                |
|     |      | [[雇主]]=>僱用勞工之是業主                                                |
|     |      | [[工資]]=>指勞工因工作而獲得報酬                                             |
|     |      | [[平均工資]]=>發生之當日前6個月內所得工資總額<br>                      該期間之總日數所得金額 |
|     |      | [[事業單位]]=>僱用勞工之單位機構                                             |
|     |      | [[勞動契約]]=>勞雇關係有從屬性契約                                            |
|     |      | [[派遣事業單位]]=>從事勞動派遣業務之事業單位                                       |
|     |      | [[要派單位]]=>依要派契約，實際指揮監督管理派遣勞工，從事工作者                              |
|     |      | [[派遣勞工]]=>受派遣單位僱用，並向要派單位提供勞務者                                   |
|     |      | [[要派契約]]=>要派單位與派遣事業單位，就勞動派遣訂定契約                                 |
