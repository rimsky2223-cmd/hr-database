
| 比較項目   | 公教人員保險 (公保)       | 公教人員退撫基金 (公退)                 |
| ------ | ----------------- | ----------------------------- |
| 制度層級   | 第一層：強制社會保險        | 第二層：職業退休金制度                   |
| 制度性質   | 確定給付制 (DB)        | 舊制：確定給付制 (DB) / 新制：確定提撥制 (DC) |
| 繳納基礎   | 以保險俸(薪)額計算        | 以本（年功）俸（薪）額加 1 倍（即兩倍本俸）為基數計算  |
| 費用分攤比例 | 個人負擔 35%，機關負擔 65% | 個人負擔 35%，機關負擔 65%             |
| 請領項目   | 養老給付（可選擇一次金或年金）   | 舊制：終身給付 / 經濟部只有勞退舊制<br>       |
| 給付性質   | 終身給付（按月領到身故）      | 舊制：終身給付 / 經濟部只有勞退舊制           |
| 主要用途   | 確保公教人員退休後的基本生活保障  | 確保公教人員退休後的所得替代率（維持原有生活水準）     |
|        |                   |                               |
