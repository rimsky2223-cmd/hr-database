
| **特性比較**   | **🥇** **勞工保險（勞保）老年給付**        | **🥈** **勞工退休金（勞退新制）**             |
| ---------- | ------------------------------ | ---------------------------------- |
| **制度性質**   | **社會保險** (社會互助基金)              | **個人專戶儲蓄** (強制提撥)                  |
| **法源依據**   | 《勞工保險條例》                       | 《勞工退休金條例》                          |
| **錢的來源**   | **三方共同繳納**：政府、雇主、勞工本人（繳納保費）。   | **雇主強制繳納** (最低 6%)，可搭配勞工自提（繳納提撥金）。 |
| **資金去處**   | 資金進入**共同基金池**，統籌運用。            | 資金進入**勞工個人專屬帳戶**，專款專用。             |
| **最高計算上限** | **投保薪資上限：**45,800              | **提繳工資上限：**150,000                 |
| **請領條件**   | 滿足一定年齡與年資即可請領。                 | 必須**年滿** **60** **歲**即可請領。         |
| **領取方式**   | **年金** (月領，活到老領到老，有終身保障，或一次領)。 | **一次金** 或 **月退休金** (領到專戶裡的錢花完為止)。  |
